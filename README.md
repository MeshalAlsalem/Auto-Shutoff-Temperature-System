# Auto-Shutoff Temperature System (Fail-Safe Prototype) 🌡️⚡

## 📌 Project Overview
This project is a prototype for a **Fail-Safe Protection System**. It uses an Operational Amplifier (IC 741), a thermistor (NTC), and a trimpot to detect dangerous heat levels like a fire. 
Instead of just being a normal alarm, this circuit is designed to **automatically cut off power** when heat rises. In this prototype, the LED lamp represents a sensitive machine or a computer server. When the fire gets close, the system turns OFF the machine instantly to protect it from damage.

## ⚙️ How It Works
1. **Thermistor (NTC):** Senses the heat. When temperature goes up, its resistance goes down.
2. **Trimpot (Variable Resistor):** Sets the safe temperature limit.
3. **Op-Amp 741:** Acts as the brain. It compares the heat level. If the heat passes the safe limit, the IC cuts the power and turns the LED OFF.

## 🛠️ Components Used
* IC 741 Operational Amplifier
* NTC Thermistor (5D-15)
* 10kΩ Potentiometer (Trimpot)
* 220Ω Resistor
* 10kΩ Resistor
* LED
* Breadboard and Wires
* 5V DC Power Supply

## 🚀 Real-World Uses
This simple idea can be used in big projects like:
* **Server Rooms:** Shutting down computers automatically if the AC stops working and heat rises.
* **Smart Homes:** Cutting off electricity to avoid electrical fires.
* **Industrial Machines:** Stopping motors if they overheat.
